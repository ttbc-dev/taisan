# Security review records

Per-change security review records land here as
`<slug>-<YYYY-MM-DD>.md` when a change falls in the "review required"
tier of `../review-policy.md` or when any finding survives a recommended
review.

Record shape: scope (branch/diff), verdict, findings and their
dispositions (resolved in-change or waived with reason), and the
`file:line` evidence behind each finding. Delete this README once the
first real record exists.
