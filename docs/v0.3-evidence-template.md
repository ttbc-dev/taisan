# v0.3 owner-run evidence record — template

Copy this record for each owner-run real-Worker acceptance session and
retain it in `docs/evidence/` (suggested name
`v0.3-owner-run-<run-tag>.md`). Fill every field. A field that does not
apply is `n/a` with a reason, never blank. Bracketed `[owner: …]`
fields are entered by the owner at record time.

Every result cell carries exactly one label:

- **automated fixture/contract evidence** — scripted adapters, fixture
  sources or Workers (`workloop-fixture-worker`,
  `workloop-contract-worker`), temporary/in-memory SQLite, contract or
  unit tests, and the non-live CLI transcripts in
  `fixtures/v0.3-doc/`.
- **owner-run live evidence** — a real installation, a real conforming
  Worker (not a shipped fixture), the production `github` host driver,
  real credentials by reference, and real host effects on one isolated
  repository under recorded owner authorization. The commands may be
  run by the owner or by an owner-designated operator named in that
  authorization; the label attests the authorization and the real
  environment.

A live criterion is never marked passed from an automated fixture or
contract result. Operators must redact credential values before
retaining the record. A live row that did not run is `unexercised`
with a reason; it is not `pass`.

## Redaction checklist

- [ ] No credential value appears in this record, `argv`, config text,
      command output, logs, evidence references, `request.json`,
      `report.json`, or exported artifacts.
- [ ] Only credential reference names are recorded.
- [ ] Worker `describe`/request/report captures contain no secret
      material (runtime credential is delivered only through the
      approved `/taisan/runtime-auth` path, never into the wire).
- [ ] Source bodies and untrusted remote text are bounded to stable
      references (repository, issue number, head SHA, change-request
      id, finding id), not pasted in full.
- [ ] Any suspected leak is recorded as an incident and the credential
      is rotated before the run continues.
