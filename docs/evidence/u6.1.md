## Non-claims

- Proposal → admission → Work creation is not wired in this slice;
  `Proposal` is the data surface Core will validate. The
  `proposal_admissions` replay table and config-only alternate
  admission path are owned by later U6 slices.
- "Stale source" handling is enabled, not enacted, here: every
  `SourceBinding` carries the exact revision + content digest the
  proposal was built from so admission can detect staleness; the
  freshness check itself is Core-side.
