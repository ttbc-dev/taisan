## Residual risks / open items

- The skill-path equivalence test enumerates operations mechanically
  and proves envelope equality, replay identity, and recovery-path
  parity; it does not measure an agent's reasoning quality.
- A literal process kill mid-`submit` is modeled as the documented
  lost-response scenario (the store commits, the envelope never
  arrives) — the case the recovery reconciliation exists for.
- `judge-findings` skill-path coverage appends the second `--decision`
  from the documented repeatable flag after the minimal block; the
  direct path builds both literally. Both produce the same accepted
  envelope.
