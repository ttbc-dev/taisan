invocation produced H2, and only the **new current-target round** on

## Deviations from the target profile (Profile R)

1. **Describe-probe wrapper**: the supervisor on this revision
   requires an effect-free `describe` capability probe before launch;
   `worker-shim.sh` predates it. An operator-local wrapper outside the
   repository answers `describe` and `exec`s the unchanged shim for
   every other mode. The shim code is unmodified; the wrapper is a
   recorded Profile R deviation.
2. **Workspace pre-seeding**: the isolation profile sets
   `GIT_ALLOW_PROTOCOL=file`, denying the shim's HTTPS clone. The
   operator cloned `ws-w-7` with real `git` beforehand; the shim's
   `[ ! -d .git ]` guard then skips cloning — the normal preseeded
   path, not a shim modification. `e-7`'s `artifact_recovery_exhausted`
   failure is the recorded cost of discovering this.
3. **Executor identity**: commands were executed by the Devin agent
   under the owner's #113 authorization; the GitHub-authenticated
   actor on receipts remains `shimpeiws`. Provenance is recorded
   honestly in both places.
4. **e-7 failure retained**: the first execution's launch refusal and
   artifact-recovery exhaustion are part of the evidence, not edited
   out; `e-8` is the successful execution of the same Work.
