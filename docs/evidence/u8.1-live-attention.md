Slice: U8.1-live Attention variant under issue #113. One real Work item
was submitted through the real `taisan` CLI against the isolated
repository `shimpeiws/coding-worker-smoke`, dispatched by the real
eight-phase run loop, and driven with a **non-converging** scenario

remained `paused` with **no outcome** — the designed bounded operator
gate, not a success and not a silent hang.

shims on the isolated repository; not target-profile certification
(#149, #183, #96). All facts come from the run's own SQLite store,
remote read-backs, and retained transcripts.

**Authorization**: same owner-posted #113 authorization as the success
variant (Profile R, all three variants, isolated repository, evidence
retention, expiry 2026-11-22, stop authority). Executed by the Devin

## Non-convergence design

`worker-shim-nc.sh` is the scenario Worker variant whose change always
triggers the same two review findings regardless of content — the
fixture review lane reports `s1-review.missing-docstring` and
`s1-review.unguarded-none` on every head. Combined with the Work's
fix-invocation bound, this deterministically produces the Attention
scenario: findings → judge `fix` → release → fix invocation → identical
findings on the new head → bound reached → human gate.

## What the variant proves

- Non-converging review/fix behavior is bounded: after the configured
  fix-invocation bound, the Work pauses for an operator decision rather
  than looping or claiming success.
- Attention derivation is evidence-driven (`paused_judgment`), scoped
  to a version, and `acknowledge` clears the visible attention item —
  while correctly leaving the underlying paused execution unresolved
  (the decision is still owed; acknowledgment is not resolution).
- The final remote state is honest: PR #31 open at `284f93ef`, two
  judged-but-unresolved finding rounds, no terminal outcome.

   `s1-wrap-shim-nc.sh` (answers `describe`, delegates to the unchanged
   `worker-shim-nc.sh`); shim code unmodified.
2. **Workspace pre-seeding**: `ws-w-8` pre-cloned by the operator for
   the same `GIT_ALLOW_PROTOCOL=file` reason as the success variant.
3. **Executor identity**: Devin under owner #113 authorization;
   GitHub actor `shimpeiws`.
4. **Non-converging shim**: `worker-shim-nc.sh` is itself scenario
   tooling (merged with the U8.1 prep materials); the findings it
   triggers are fixture-authored, while the checks, reviews, PR, and
   store transitions are real.
