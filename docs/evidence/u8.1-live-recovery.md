## Anomaly — `w-10`/`e-10` wedged `waiting`/`ci` (root cause confirmed)

After all apparent completion evidence existed (applied push + PR,
successful required check, sealed complete zero-finding round, positive
assessment, no pending intents, no unresolved writers), `e-10` stayed
`waiting`/`ci` for 45+ minutes with no attention and no outcome.

**Root cause (verified by instrumented replay on a `/tmp` copy of the
store; the evidence DB was never modified and all instrumentation was
reverted):**

- `s1-bridge` emits target-branch state with delivery event id
  `branch:{target_branch}:{sha}` — **not scoped to the work** — and an
  identical fact body. Store dedupe is global per
  `(scope, source, event_id)`, so `branch:main:30f43fa…` — first
  recorded for `w-9` — made `w-10`'s identical emit a `Duplicate`
  (`bridge-unarmed-w10.log`). **No `main` BranchState observation
  exists under `w-10`.**
- Core's `current_target` derives `DiffTarget.target_revision` only
  from the work's own BranchState observations → `None` for `w-10`,
  while the sealed round's target carries `Some(30f43fa…)`. Exact
  `DiffTarget` equality fails → `latest_round_for_target` → `None` →
  `assess_completion` exits at the review-lane `no_round` gate on every
  evaluation (instrumented run printed `gate=no_round`; injecting a
  synthetic `w-10`/`main`@`30f43fa` observation made the same
  evaluation print `SUCCEEDED`).
- Compounding factor: completion is strictly observation-driven — once
  every fact dedupes, `assess()` never re-runs, and the missing
  observation can never be re-recorded (always `Duplicate`), so the
  wedge is permanent and silent (no attention derivation).

Full write-up: `evidence/anomaly-w10.md` (scenario state root). This
is a **scenario-adapter defect**, not a Core transition defect; a
follow-up issue is recommended (bridge event-id work-scoping; optional
Core review of dedupe subject-scoping and re-assessment paths). Owner
decision pending.

`cmd-23` (`release-judgment` probe on `w-10`) was correctly **rejected**
`ineligible` — no paused execution / no open findings — recorded as
negative-path evidence.
