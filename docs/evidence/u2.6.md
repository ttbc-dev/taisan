## Configuration under test

Eligibility is exercised against explicit per-category settings
(`CategorySettings` with `cas`), and against a real temporary state
root for the CLI smoke run. The closed documented defaults apply when a
category has no explicit setting. PlanBounds exercised: default
(`max_bodies: 256, max_bytes: 1 GiB`) and an explicit
`max_bodies: 2` bound.
