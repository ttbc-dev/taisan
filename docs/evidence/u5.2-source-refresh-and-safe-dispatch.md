## Platform note — localized `ps` parsing

On this host (ja locale), `ps` renders `lstart` weekdays in CJK
(`火 11/10 …` instead of `Tue Nov 10 …`). The supervisor's
process-table and `lstart` parsers assume the C locale's ctime format,
so every `ps` read surfaced `Failed`/`Unknown` process evidence, spawn
reconciliation could never complete, and 12 supervisor contract tests
failed closed (executions stuck in `Stopping`). This predates the slice
— it is an adapter boundary bug, not a test-environment issue — and it
would break U5.2's ready/spawn reconciliation claim on any
non-English-locale POSIX host. Fix: `ps_output` now forces `LC_ALL=C`
on its `ps` invocations so the parser always sees the format it was
written for (`crates/workloop-exec/src/supervisor.rs`).
