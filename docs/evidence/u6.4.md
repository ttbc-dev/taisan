| Stale input | `a_stale_source_read_holds_the_work_for_reapproval` — changed authoritative read ⇒ `SourceGate::Changed`, Execution paused, `SpecReapproval` prerequisite; translation carries the recorded read verbatim so staleness cannot be laundered | pass |
| Denied input | `non_allowlisted_source_is_refused`, `excluded_issue_is_refused`, `closed_issue_is_not_proposed`; `an_unallowlisted_source_is_refused_before_any_command`; `an_unparseable_selector_section_is_refused_at_the_propose_boundary`; CLI envelope surfaces typed skip reasons including `conflicting_facts` and reports `truncated` bound cuts | pass |

| Outage isolation | `a_missing_selector_section_blocks_nothing_else` — bounded config error for `propose`, manual submit and existing Work unaffected; `zero_proposals_is_data_not_a_failure` | pass |
| Operator-visible replay keys and provenance | batch envelope items carry `replay_key` (`proposal/<selector>:<key>`) and `command_id`; `command-result --origin selector --replay-key <key>` recovers the recorded decision — proven in `proposals_are_admitted_through_the_normal_submit_path` | pass |
