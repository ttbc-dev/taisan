## Incidents inside the run (recorded, not hidden)

1. **Run 1 abandoned**: the first shim revision's round detector used
   `grep -q` in a pipeline under `pipefail`; `grep -q`'s early exit
   SIGPIPE'd `git log` (141), so the Fix round re-ran round 1 and
   duplicated `greet()`. The run was cancelled (`w-1` cancelled in
   `workloop-run1.db`), `shimpeiws/coding-worker-smoke#12` closed, and
   the seed was replaced under a new run tag per the reseed rule.
2. **Run 2 `e-1` failed**: a malformed if/else in the second shim edit
   killed the worker before it produced an artifact;
   `artifact_recovery_exhausted` settled `e-1`, and `retry` created
   `e-2` — the Recovery leg above is real, not staged.
3. **Core gap found and fixed in-slice**: `maybe_publish`'s push stage
   treated any applied `push_ref` as satisfied, so a fix artifact could
   never republish. The stage now requires the applied push's
   `produced` to equal the current artifact digest; the stale-applied
   fall-through records a fresh intent (this commit).
