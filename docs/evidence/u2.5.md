## Configuration under test

Eligibility is exercised against explicit per-category settings:
`CategoryLimits::new(max_age, max_bytes)`, where `None` is `unlimited`
on that axis. The catalogue's present bodies supply the authoritative
age (`created_at`), size (`size_bytes`), category and pin state. The
scenario matrix uses one category (`cas`) with values chosen per case:

| Axis | Values exercised |
| --- | --- |
| `max_age` (seconds) | `5`, `100`, `1000`, `10000`, `2_592_000`, `None`; omitted-key `cas` default `7_776_000` |
| `max_bytes` | `1`, `5`, `9`, `10`, `15`, `19`, `100`, `1000`, `1_073_741_824`, `None`; omitted-key `cas` default `42_949_672_960` |
| Documented defaults asserted | `workspace` = `2_592_000` s / `21_474_836_480` B; `cas` = `7_776_000` s / `42_949_672_960` B; `archive` = unlimited |
| `pin_state` | `none`, `active`, `paused`, `recovering`, `unknown-effect` |
| Age relative to limit | younger, exactly equal, older |
| Category bytes relative to cap | under, exactly equal, over |
