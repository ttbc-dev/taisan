# v0.2 owner-run evidence record — template

Copy this record for each owner-run session and retain it in
`docs/evidence/` (suggested name
`v0.2-owner-run-<run-tag>.md`). Fill every field. A field that does not
apply is `n/a` with a reason, never blank. Bracketed `[owner: …]` fields
are entered by the owner at record time.

Every result cell carries exactly one label:

- **automated fixture/contract evidence** — scripted adapters,
  fixture sources or Workers, temporary/in-memory SQLite, contract or
  unit tests.
- **owner-run live evidence** — a real installation, real eligible
  Issues, real source reads, an owner-supplied Worker, and real host
  effects under recorded owner authorization.

A live criterion is never marked passed from an automated fixture or
contract result. Operators must redact credential values before retaining the record. A live row that did not run is `unexercised` with a
reason; it is not `pass`.

## Redaction checklist

- [ ] No credential value appears in this record, `argv`, config text,
      command output, logs, evidence references, or exported artifacts.
- [ ] Only credential reference names are recorded.
- [ ] Source bodies and untrusted remote text are bounded to stable
      references (repository, issue number, run id, head SHA, check
      identity), not pasted in full.
- [ ] Any suspected leak is recorded as an incident and the credential
      is rotated before the run continues.
