# S1 scenario fixtures

Machine-readable fixtures for the S1 live acceptance scenario — see
[docs/s1/README.md](../../docs/s1/README.md) for the materials index.

**Private references.** These fixtures record
`shimpeiws/coding-worker-smoke`, a private repository owned by this
project's owner, as the scenario target identity. Every link and `#N`
citation to it resolves only for the owner (they 404 publicly). The
recorded values are scenario data, kept verbatim under the owner
publication decision (#438).
